# D3’s Digital Birthday Surprise 💌

A mobile-first interactive birthday gift built with React and Tailwind CSS.

## Experience

- Open the realistic gift box by clicking its lid.
- Use the objects inside—not menu buttons—to navigate:
  - Envelope → editable vintage letters
  - Bouquet → kitten flower page
  - Camera → memories gallery
  - Cake → wish, candle, countdown, cutting, slice, note, and final popup sequence
- Edit letters and media metadata in `src/content/content.json`.

## Development

```bash
npm install
npm run dev
```

Production check:

```bash
npm run build
npm run lint
```
